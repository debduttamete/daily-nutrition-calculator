# Daily Nutrition Calculator

A responsive nutrition calculator built with HTML, CSS, and JavaScript,

##Calculation & Logic

The calculator provides estimates, not medical advice.

BMI: Weight ÷ height²
BMR: Estimated using the Mifflin–St Jeor equation.
Daily calories: BMR × activity level to estimate maintenance calories.
Goal calories:
Maintain → maintenance calories
Lose → calorie deficit
Gain → calorie surplus
Protein: Based on body weight and the selected protein target.
Fat: Based on a percentage of daily calories.
Carbohydrates: The remaining calories after protein and fat.
Water, fiber & movement: General daily reference targets.
Trainer Mode

Trainers can customize the activity multiplier, calorie deficit/surplus, protein, and fat targets. Carbohydrates adjust automatically based on the remaining calories.

Note: These numbers are starting-point estimates. Individual needs can vary, so real-world progress, food intake, and body-weight trends should be considered when adjusting a plan.
